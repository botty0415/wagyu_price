# Git Lesson

## リモートリポジトリとローカルリポジトリとはそれぞれ何でしょうか？

- リモートリポジトリは、ウェブ上の保存場所。他の人と共有出来る
- ローカルリポジトリは、自身のPC上の保存場所

## プッシュとマージの違いは何でしょうか？

- pushは、自身の作業を共有する作業
- mergeは、複数の作業を共有する作業

## コミットとプッシュの違い

- コミットは自分のPC上に作業の記録を残すこと
- プッシュはその記録をみんなで共有するためにオンライン上に送る事


## コミットのメッセージはどのように書いてあげるのが最適でしょうか？

- 主に「何を」「なぜ」変更したかの記載

## ローカルでマージするフローと、プルリクエストでマージするフローの違いは何でしょうか？

- ローカルは基本的に自分のローカル環境で完結するのに対し、プルリクエストは、レビュアーに内容を確認してもらい、フィードバックを受けマージ、メインに統合する形

## コンフリクトを起こしてしまった場合、どう対処すべきですか？

- 原因を特定し、解決策を模索

   - 　先にマージされた変更内容を取り込む
   - 　後にマージしようとしている内容を取り込む
   - 　どちらの内容も取り込む
